# 难得民谣 · 订座小程序（一期）

一间叫「难得民谣」的民谣酒馆，自己的微信小程序。
第一步只做一件事：**让客人在手机上订桌子**，先在自家店里跑通，
之后再把点单从美团搬过来（见 [二期计划](docs/二期-点单替换美团.md)）。

原生微信小程序，没有用任何框架，数据层现在跑在本地（mock + 本地缓存），
接云开发时只需要改 `miniprogram/utils/api.js` 一个文件，页面代码一行都不用动。

---

## 先看长什么样

两种方式：

**1）浏览器里看（不用装开发者工具）**

```bash
cd 难得程序/tools
npm install          # 只装一个 sharp，用来生成图标
npm run preview      # 把真实的 WXML/WXSS/JS 渲染成静态网页
cd ../preview && python3 -m http.server 8080
```

打开 <http://localhost:8080> ，八个页面并排摆在手机壳里。
这页是用脚本渲染**真实源码**出来的，改了代码重跑 `npm run preview` 就会同步。

**2）微信开发者工具（能真正点、真正下单）**

导入项目 → 目录选 `难得程序/`（不是 miniprogram 子目录）→ AppID 先用「测试号」。

## 想改内容，改这几个地方

| 想改什么 | 改哪里 |
|---|---|
| 店名、地址、电话、营业时间、到店须知 | `miniprogram/utils/data.js` 的 `shop` |
| 有几张桌、分几个区、最低消费 | `data.js` 的 `zones` |
| 可订时段 | `data.js` 的 `slots` |
| 每周演出（周一到周日各唱什么） | `data.js` 的 `weeklyLineup` |
| 店员模式口令 | `pages/staff/staff.js` 的 `PASS` |
| 配色、字体、圆角、按钮样式 | `miniprogram/app.wxss` 顶部的变量 |
| 头图 | 换掉 `assets/images/hero.jpg`（1050×560 左右） |
| 图标 | 改 `tools/make-icons.js` 里的 SVG 线稿，再 `npm run icons` |

## 一期做完了什么

- 订桌全流程：日期（14 天，标出有演出的晚上）→ 时段（过点的自动灰掉）→ 人数 → **可视化桌位图**选桌 → 填称呼手机 → 生成订座凭条
- 订座凭条做成**票根**样子：取号 `ND-1016-07`、撕口、条码、到店三步
- 我的预约：还没去 / 去过的，状态印章（待确认 / 已确认 / 已到店 / 已取消 / 已完成）
- 演出页：两周歌单，点一天直接订那天的桌
- 店员模式：吧台口令进入，看今天几桌几人、确认留座 / 已到店 / 结账 / 取消
- 民谣风格的 UI：牛皮纸底 + 纸张颗粒、宋体标题、暖木琥珀色、手绘线稿图标、票根与印章

## 一期还没做（故意留的）

- 真后端：现在数据存在本机，换一台手机看不到。**上云是第一件要补的事**（见 docs/上线清单.md）
