# 《记忆时空》设计方向 v1.1

> 基于《战魂铭人》(Otherworld Legends) 玩法底层 · 单机优先、联机可选的像素动作肉鸽 · 手机游戏
> 阶段：方向设计（不写代码）→ 分模块筛选确认 → 全部确认后再生成 Demo

---

## 1. 一句话定位

把《战魂铭人》「房间制地牢 + 爽快连击 + 道具构筑」的成熟骨架，做成一款 **单机完整可玩、联机可选加倍** 的原创像素肉鸽：

> **一个人能完整通关；2~4 名好友组队则靠团队连携，一局 20 分钟修复十二段断裂的历史记忆。**
>
> 视觉气质：**梦核**（同一地点在四段断裂时空里的四副面孔，迷雾朦胧）+ **老式电脑模拟**（世界边缘溶解为数字虚空）。

题材、美术、角色、文案全部原创，不换皮、不侵权。

### 2.1 吸收（继承的玩法骨架）

| # | 机制 | 说明 |

### 2.2 改变（差异化定位）

| 维度 | 战魂铭人 | 本项目《记忆时空》 |
|------|----------|--------------------|
| 联机地位 | 附加模式（上线两年后才补） | **单机为一等公民，联机为可选模式**（立项起就同步设计，但绝不依赖联机） |
| 核心乐趣 | 个人构筑爆发 | 单人：构筑爆发；联机：**团队连携**（元素连锁、合体技、道具互助、分工） |
| 局外养成 | 偏重（修罗之力、神性等刷点） | 轻养成：只解锁选项，不堆数值，好友间无战力差 |
| 单局时长 | 30~40 分钟 | **20~25 分钟**，贴合朋友聚会节奏 |
| 题材 | 全球历史英雄大杂烩 | **多元历史英雄 + "记忆回廊"原创框架**（见 §3） |
| 美术 | 复古写实像素 | **粗颗粒像素** + 高饱和 + 时代风情 + 迷幻电气气质（见 §4） |

### 2.3 合规红线（重要）

- 玩法机制不受版权保护，可以借鉴；但 **美术素材、音乐音效、文案、角色名、道具名、关卡名必须全部原创**。
- 不做换皮：所有内容资产从零创作。

## 3. 世界观主题（已确认：多元历史英雄）

### 3.1 设定框架
时间之上存在一座「**记忆回廊**」，收纳着人类历史所有被遗忘的瞬间。某一日回廊断裂，四段时代记忆错乱崩塌，不同时代的英雄被卷入其中。玩家（单人或小队）要一层层穿过四个错乱的时代，修复记忆节点，查明回廊断裂的真相。

### 3.2 四幕 = 同一地点在四段断裂时空里的四副面孔

> 核心创意：所有场景都是**同一个地方**——「记忆锚点」。记忆回廊断裂后，这一段记忆被不同时代的力量轮流扭曲，于是同一座城在四个时空里呈现出四种样貌（梦核感：似曾相识又处处陌生）。

| 幕 | 时空 | 同一地点的样貌 |
|----|------|----------------|
| 1 | 大唐长安·上元灯会 | 木楼灯笼挂满街，灯会之夜被永久定格 |
| 2 | 古埃及·沙漠陵墓 | 同样的街道沉入黄沙，变成砂岩墓道与壁画长廊 |
| 3 | 维多利亚·蒸汽都市 | 同样的街廓被齿轮与铜管覆盖，成了发条囚笼 |
| 4 | 亚特兰蒂斯·深海王城 | 同样的街巷淹没在深海，珊瑚爬满宫阙 |

- 每一幕都会出现**同一个地标**的变体（同一座戏台/门楼/古井），提示玩家"这里是同一个地方"
- 雾气、光晕、低饱和 + 高对比，营造梦核的朦胧感

## 4. 像素美术风格设计

### 4.1 技术路线：2.5D 粗颗粒像素
继承战魂铭人已验证的「**3D 低模场景 + 像素贴图 + 手绘逐帧精灵**」方案，但像素程度整体加强：

- **更粗的颗粒**：纹素密度翻倍（场景 64px/米），角色战斗精灵约 48~64px，肉眼可见的像素格子
- **更狠的色阶化**：禁用抗锯齿，大面积有序抖动 + 半调网点，保留"老磁带/胶卷"式的颗粒质感
- **限色调色板**：每幕 12~16 色，整体高饱和，夜色场景用高对比暗部

### 4.2 风格参考：赞诗乐队专辑封面（已获取）
- 参考对象：《跳金水》封面（冷灰蓝水色）+《神农尝百草》封面（深棕赭石大地色）
- 参考文件：`docs/concepts/refs/赞诗-跳金水-封面.jpg`、`docs/concepts/refs/赞诗-神农尝百草-封面.jpg`
- 提取的视觉气质：
  - **双色调冲突美学**：冷灰蓝（水/雾）× 深赭棕（土/草），高对比暗部
  - **胶片颗粒**：粗粝质感、迷幻光晕，呼应乐队"民族 × 电子"的反差
  - **古意**：山水草木的东方意象，不做廉价国风符号堆砌
- 应用方式：调色板与后处理参考（非直接复制），正式定调待用户确认融合效果
- **梦核气质（用户新增要求）**：
  - 同一地点在四段时空里的四副面孔——「似曾相识又处处陌生」的错位感
  - 朦胧：低空雾层、柔光晕、远景点到为止（不画实）
  - 低饱和主色 + 每幕 1~2 个高饱和点缀色；空荡街道的"限阈空间"感
- **老式电脑模拟 + 游戏内数字虚空边界（用户澄清修正）**：
  - 场景看起来像**老式电脑实时渲染出来的模拟世界**：CRT 扫描线、轻微色散（RGB 分离）、低分辨率像素颗粒、偶发网格线
  - **故障在游戏世界内部，不在屏幕/窗口上**：可玩区域像一座**漂浮在无尽数字虚空里的"渲染舞台"**——房间外墙、地图边缘处模拟正在崩解：墙体碎成像素块飘散、裂缝透出红白静态噪点与撕裂、墙外是纯黑数字虚空（参考《神奇数字马戏团》的世界边缘 + 《尼尔：机械纪元》的数据腐坏）
  - 这是**世界几何与特效**（墙体溶解、虚空、漂浮数据碎片），不是屏幕后处理
  - 玩法联动：隐藏房入口的"涟漪"特效改为"数据裂缝"；Boss 登场时可触发全屏故障波纹

### 4.3 规格表

| 项目 | 规格 |
|------|------|
| 视角 | 斜 45° 俯视，镜头低角度跟拍；联机时智能拉远保证 4 人同屏 |
| 角色 | 3 头身 Q 版，战斗精灵 48~64px，粗颗粒块面感 |
| 场景 | 3D 低模 + 像素贴图，纹素密度 64px/米（颗粒感强） |
| 调色板 | 每幕 12~16 色主色板 + 4 点缀色 |
| 光照 | 烘焙光照 + 屏幕后处理（色阶化 + 有序抖动 + 胶片颗粒） |
| 特效 | 手绘序列帧（刀光/爆炸/法术）+ 震屏 + 顿帧 2~4 帧 |
| UI | 像素中文字体 + 像素面板 + 弹跳伤害数字 |

### 4.6 UI/HUD 设计（按用户提供的游戏界面参考描述）

**总体效果**："复古像素 RPG + Q 版卡通冒险 + 移动端动作 + 营地大厅 + 丰富 HUD + 虚拟摇杆"，要有完整商业手游 UI 的感觉。

| 项目 | 规格 |
|------|------|
| 视角 | 固定 2D 俯视斜角（3/4 view），镜头固定高度/角度，以玩家为视觉中心平滑跟随 |
| HUD 布局 | 顶部：资源条（金币/宝石/能量/材料，大像素图标 + 白色数字）；左上：头像 + 等级 + 血条/护盾；右上：系统按钮（设置/背包/任务/邮件/商城） |
| 操作区 | 左下：半透明圆形虚拟摇杆；右下：大型圆形攻击键 + 技能键（带冷却转圈）+ 闪避 |
| 互动提示 | 靠近 NPC/宝箱/商店/工作台时出现**圆形互动提示**（白色粗像素描边 + 黑色图标）；NPC 头顶显示中文名字 |
| UI 视觉 | 与像素世界统一：粗黑像素描边、白色高亮边、半透明圆形**实体按键感**（复古游戏按键，非扁平 App UI）；按钮大、图标粗犷易点 |
| 色彩 | 明亮卡通 RPG 配色（大量明亮的绿/棕/蓝/红/黄）——大厅 UI 层用；地下城世界层保持梦核朦胧 + 数字虚空 |

**注意点（已确认）**：UI 与地下城**统一气质**——UI 面板同样做旧处理（扫描线、像素噪点、暗色底），不做"明亮 UI vs 暗黑世界"的强反差。

### 4.7 大厅（古风客栈「暂诗客栈」）
大厅是一座**古风大饭店/客栈**，室内多房间串联（不再空旷）：

| 区域 | 功能 |
|------|------|
| **正厅（大堂）** | 选人、组队、好友集合；桌椅、掌柜柜台、楼梯，NPC 掌柜/伙计 |
| **侧厅** | 商店（道具/药品购买，联机可合购） |
| **后院** | 锻造（装备/道具合成升级）、天井（天气与时间直接可见） |
| **天井** | 露天院落，承接时间与天气表现（雨落天井、雪积屋檐） |

- 客栈与地下城同一套渲染气质：粗颗粒像素 + 老式电脑模拟的朦胧感 + 暖灯笼内景（比地下城更安全、更暖）
- 店名（已确认）：**暂诗**（"暂"=旅人短暂停留；"诗"=掌柜是收集记忆残片的旧诗人）
- 房间之间用门/走廊串联，玩家可自由走动；联机时好友的像素小人就在客栈里一起逛

### 4.8 大厅时间与天气系统

**时间**（循环变化，影响客栈内外光照氛围）：

| 时间 | 氛围 | 视觉 |
|------|------|------|
| 清晨 | 冷青晨雾 | 低角度冷光、薄雾、露水反光 |
| 正午 | 明亮通透 | 强顶光、天井阳光直射、光影分明 |
| 黄昏 | 暖金怀旧 | 金色斜阳、长影、灯笼渐亮 |
| 深夜 | 静谧幽蓝 | 月光、灯笼暖光为主、星点、最浓的梦核感 |

**天气**（随机/可选，影响天井与音效氛围）：

| 天气 | 视觉表现 | 氛围加成 |
|------|----------|----------|
| 晴 | 明亮、光斑 | 默认状态 |
| 雨 | 雨丝、积水倒影、屋檐滴水 | 雨声白噪音 |
| 雪 | 飘雪、积雪屋顶与地面 | 静谧、环境音变闷 |
| 阴 | 灰云压顶、平光 | 画面低饱和 |
| 雾 | 浓雾弥漫、远景隐没 | 最梦核、可视距离缩短 |

- 实现（已确认）：**时间按游戏内循环轮换**（每几分钟一转，登录一局内能看全四时）；**天气随机刷新为主**，玩家可在天井/观星台手动切换
- 可玩性钩子（可选）：深夜掌柜出售限定道具；雨天某 NPC 出现——后续再定



## 5. 游戏场景设计

### 5.1 关卡结构
- 常规模式：**3 幕 × 4 层 = 12 层**，每幕第 4 层为 Boss 层（继承战魂铭人结构）
- 快速模式：2 幕 × 4 层 = 8 层，约 15 分钟
- 房间随机拼接，每层保底 1 商店 + 1 隐藏房
- 单机 / 联机使用同一套关卡，联机仅追加人数缩放与协作房间

### 5.2 房间类型表

| 房间 | 标记色 | 内容 | 联机变体 |
|------|--------|------|----------|
| 战斗房 | 红 | 清怪后开门 | 精英房概率随人数提升 |
| 商店房 | 蓝 | 买道具/药品 | 可合购、可互相请客 |
| 宝箱房 | 橙 | 道具/金币 | 宝箱"分赃"分配界面 |
| 隐藏房 | 紫 | 涟漪入口，每层 1 个 | 高收益，双人机关门 |
| 出口房 | 绿 | 通往下一层 | 需全员到齐才能开门 |
| 协作机关房 | 金 | 双人踏板/机关 | **仅联机出现** |

### 5.3 四幕场景详设（同一地点 · 四副面孔）

| 幕 | 同一地点的样貌 | 敌人 | Boss | 场景机制 |
|----|----------------|------|------|----------|
| 1 大唐长安（新手幕） | 灯会街道：木楼、红灯笼、戏台 | 幻影戏偶、灯妖、衙门捕快（精英） | 千面幻戏师 | 戏台机关喷火、机关鼓点 |
| 2 埃及陵墓 | 黄沙淹没同一条街：砂岩墓道、壁画长廊、圣甲虫大厅 | 木乃伊、圣甲虫、安努比斯守卫 | 永生法老 | 流沙周期性涨落，需站高台 |
| 3 蒸汽都市 | 齿轮覆盖同一条街：齿轮街区、锅炉房、空中栈道 | 发条兵、蒸汽机兽 | 机械之心 | 传送带强制位移，蒸汽喷口击飞 |
| 4 亚特兰蒂斯 | 深海淹没同一条街：琉璃宫阙、珊瑚回廊、深渊祭坛 | 深潜者、珍珠贝卫 | 深海执政官 | 低重力区 + 洋流传送阵 |

- **贯穿地标**：每幕都保留「戏台 / 门楼 / 古井」同一组地标的变体，强化"同一地点"的梦核错位感
- **共享氛围**：低空雾层、柔光晕、朦胧远景，四幕统一后处理；CRT 扫描线 + 轻微色散
- **数字虚空边界**：房间外墙与地图边缘溶解为数字虚空——墙体碎成像素块、裂缝透出红白噪点、墙外纯黑虚空（世界内的几何特效，非屏幕特效）

### 5.4 叙事彩蛋（低优先级）
每幕隐藏文案、记忆碎片，讲述该时代英雄的生前故事与回廊断裂的真相。

### 5.5 房间拼接规则与机关（关卡内）

**A. 每层房间结构**
- 每层 = 若干房间随机拼接：入口房（出生）/ 出口房（下一层）/ 战斗房 ×N / 精英房（概率）/ 商店房（保底 1）/ 宝箱房 / 隐藏房（保底 1）/ 协作机关房（仅联机）
- 每幕第 4 层为 Boss 房
- 生成规则：出口房与入口房直线距离 ≥ 3 个房间；房间之间以门/通道相连；小地图迷雾未探索区域不可见
- 隐藏房入口 = **数据裂缝**（替代战魂铭人的涟漪）：某战斗房墙面出现闪烁裂缝，靠近互动进入

**B. 机关设计（每幕主题 + 通用）**

| 幕 | 主题机关 |
|----|----------|

- 幕4 **深海执政官**：低重力场、洋流推拉、触手横扫

## 6. 游戏玩法设计

### 6.1 单局核心循环（单人 / 联机通用）
```
（可选）组队大厅 → 选角色/难度 → 幕1第1层 → [ 探索房间 → 战斗/购物/开箱
→ 升级选强化(3选1) ] 循环 → 打 Boss → 下一幕 → 通关结算
→ 魂币解锁角色/皮肤 → 再开一局
```

### 6.2 单机模式设计（一等公民）
- 单人可完整通关全部内容：角色、道具、隐藏房、难度、剧情均单人可达
- 难度以**单人基准**设计；联机时敌人按人数缩放（§7.5）
- 单机死亡：消耗复活币原地复活，无复活币则结算（保留部分魂币）
- 联机专属内容（协作机关房、合购等）只做"加分项"，单机内容 100% 完整

### 6.3 战斗系统
- **布局（横屏）**：左摇杆移动；右下：普攻（大键）/ 闪避 / 技能A / 技能B；右上：主动道具、暂停
- **打击感五件套**：顿帧 / 震屏 / 击退+硬直 / 受击闪白 / 伤害数字弹跳
- **辅助索敌**：轻推普攻自动转向最近敌人
- **元素状态**：灼烧 / 冰冻 / 中毒 / 麻痹
  - 单人可用：元素状态互相触发（火+毒=爆燃等）
  - 联机升级为**团队元素连锁**：队友配合触发更强效果

### 6.4 角色设计（首发 4 名，全部原创，来自不同时代）

| 角色 | 时代 | 定位 | 武器 | 技能A / 技能B | 上手 |
|------|------|------|------|---------------|------|
| 谢无痕 | 大唐 | 近战均衡 | 长剑 | 剑气斩 / 影分身 | ★★ |
| 哈尔瓦 | 北欧 | 坦克控场 | 重盾战锤 | 山崩（眩晕）/ 铁壁嘲讽 | ★ |
| 阿雅 | 蒙古草原 | 远程输出 | 弓 | 三连射 / 箭雨 | ★★ |
| 内芙塔 | 古埃及 | 辅助召唤 | 权杖 | 圣甲虫护主 / 生命之泉 | ★★★ |

每角色：普攻三连段 + 闪避 + 2 技能 + 1 被动；局内升级时技能强化三选一。联机时四名角色天然构成"坦 / 输出 / 辅助"分工。

### 6.5 肉鸽道具系统
- 局内 **4 被动格 + 1 主动格**，道具分 白/蓝/紫/金 四品质
- 首发 40 件设计示例（名称全部原创）：
  - 白：磨刀石（普攻+10%）、轻羽靴（移速+8%）、铜钱串（金币+20%）
  - 蓝：流火剑穗（普攻概率点燃）、荆棘符（反弹伤害）
  - 紫：千重镜（普攻附带幻影）、定风波（受击后短暂无敌）
  - 金：千锻钢（普攻+30%）、爆燃瓶（火毒爆燃）
  - 金 · **联机系列**：同心结（队友暴击共享）、烽火令（全队攻击光环）、杏林春暖（拾取治疗共享给队友）——单机时该系列不出现
- 合成公式示例：磨刀石 + 磨刀石 = 千锻钢；灼烧符 + 毒囊 = 爆燃瓶
- 掉落来源：清房 / 宝箱 / 隐藏房 / 精英怪

### 6.6 局外养成（轻量化、反刷）
- **魂币**：通关结算获得 → 解锁新角色、皮肤
- **天赋**：每角色 3 条线，但**只解锁机制选项、不叠加数值**，好友之间无战力差
- 无体力、无每日任务；皮肤纯外观

### 6.7 难度系统
- 三档基础难度：普通 / 困难 / 修罗
- **诅咒自选**（Hades 式热度）：开局自选诅咒（敌人+30%血 / 商店涨价 / 迷雾更浓）换取魂币加成

### 6.8 商店系统（两处商店）

**A. 局外商店 = 暂诗客栈·侧厅**
- 掌柜是收记忆残片的旧诗人（NPC）；卖：角色皮肤、配方、装修（客栈家具/灯笼样式，改变大厅外观）
- 货币：魂币（通关获得）
- 与时间/天气联动：深夜出现"限时柜台"（限定商品）；雨天掌柜讲故事（赠送小道具）

**B. 局内商店 = 地下城商店房（每层保底 1 间）**
- 卖：道具、药品、武器临时强化；4~6 件随机商品，价格按品质
- 货币：局内金币（清房/宝箱/隐藏房掉落）

| 品质 | 参考定价（金币） |
|------|------------------|
| 白 | 30~50 |
| 蓝 | 70~110 |
| 紫 | 150~220 |
| 金 | 350~500 |
| 药品 | 15~30 |

- **联机玩法（差异化）**：
  - 合购：金币不够时，队友可补差价，道具归出钱方协商
  - 请客：给队友买道具直接赠送
  - 隐藏商品：某商品需"队伍总金币达到 X"才解锁，促使团队攒钱

**C. 商店 UI 规范（已确认：货架视角购买）**
- 购买界面为**客人视角**：玩家走近货架/摊位后，镜头切到货架正面——商品直接陈列在货架上（瓶罐、武器挂架），玩家点选货架上的商品即可购买，**不做抽象全屏商品面板**
- 货架分若干格位，每格一件商品，价格标签挂在商品下方；缺货格位空置
- 客栈侧厅与地下城商店房共用同一套"货架视角"交互
- 全局 UI 统一：暗色像素面板 + 白色高亮边 + 粗黑描边；图标大、价格清楚

### 7.1 定位
**单人完整可玩是底线；联机是可选的好友模式**：2~4 人纯合作，不对战；一个房间码走天下。

### 7.2 房间系统（继承战魂铭人的成熟方案）
- **房主**：创建房间 → 设人数上限（2/3/4）、公开/私密 → 生成 **6 位邀请码** → 分享给好友
- **成员**：输入邀请码直接加入（好友联机不受任何门槛限制）
- **快速加入**：公开房间列表（可选功能，后期再加）
- **大厅（客厅）**：角色展示、换皮肤、表情、房主踢人 / 换幕选难度；全员准备后开战

### 7.3 网络同步架构（关键决策）

**推荐：房主权威 + 状态同步**
- 房主跑整个世界模拟（敌人 AI / 掉落 / 房间状态）
- 客户端对自己的角色做**本地预测**（移动、普攻立即响应），定期被房主校正
- 敌人与其他玩家位置做插值平滑
- **不采用帧同步（锁步）**：手机网络抖动大，一人卡全队卡

**网络层**：测试版用 UDP(KCP) + WebRTC 打洞直连，打洞失败走云中继；轻量云服务器跑信令（房间码、打洞、重连票据）。

**带宽预算**：每人上行 20~40 KB/s；4 人局房主下行 <120 KB/s，4G 网络无压力。

### 7.4 联机专属玩法（差异化的灵魂）
1. **团队连携技**：特定技能组合触发合体技（例：哈尔瓦嘲讽聚怪 → 阿雅箭雨收割）
2. **团队元素连锁**：火+毒=爆燃、冰+重击=碎冰、水+雷=感电
3. **道具互助**：商店合购、每层 1 次道具交换、宝箱分赃界面
4. **救援机制**：死亡 → 倒地流血 15 秒 → 队友读条 2.5 秒拉起；局内掉落共享复活币
5. **沟通系统**：表情轮盘 / 场景标记 ping / 快捷语音
6. **协作机关房**：双人踏板、同时按键等联机专属房间

### 7.5 稳定性设计
- **断线重连**：凭房间码重连，恢复局内状态
- **掉线托管**：队友 AI 接管；房主掉线测试版先结束本局（后期做房主迁移）
- **人数平衡**：敌人血量随人数缩放（2 人 ×1.9 / 3 人 ×2.7 / 4 人 ×3.4），掉落同步放大
