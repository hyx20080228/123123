# 精调 · 弦乐器调音器

一个把**精度**放在第一位的调音 App：浏览器 PWA 直接用，也可打包成 Android APK
（见 [`android-build/README.md`](android-build/README.md)）。

面向吉他 / 尤克里里 / 4·5·6 弦贝斯 / 小提琴 / 中提琴 / 大提琴 / 曼陀林，
以及半音（通用）模式；吉他内置 12 种调弦（标准、Drop D/D、半音/全音降、
DADGAD、Open G/D/E/A/C、Nashville）。另含节拍器、和弦/单音参考音、
A4 = 415–466 Hz 校准、调音历史与偏差曲线。

## 精度（合成信号基准，全部可复现）

| 场景 | 平均绝对误差 |
|------|-------------|
| 算法固有精度（完全谐波信号，B0–C7 全音域 238 音） | **0.044 音分** |
| 吉他全指板 120 个音（6 弦 × 0–19 品） | 0.079 音分 |
| 真实钢弦非谐性（稳定后读数 + 刚度补偿） | ≤0.3 音分 |
| 抗噪 SNR 35 dB（含 50 Hz 工频哼声） | 0.12 音分 |
| 抗噪 SNR 18 dB | 0.38 音分 |
| 基频极弱（拨弦点近弦中点，h1 几乎缺失） | 0.30 音分 |
| 贝斯低音缠弦（B≈4e-4，已补偿） | 0.23 音分 |
| A4 = 415/432/440/442/446/466 Hz | ≤0.17 音分 |
| 连续读数抖动（卡尔曼平滑后） | 0.27 音分 |
| 八度误判（全部场景累计） | **0 次** |
| 单帧分析耗时 | ≈2 ms（手机可流畅实时） |

完整输出见 [`tests/BENCHMARK.txt`](tests/BENCHMARK.txt)。
参考量级：人耳经训练约可分辨 3–5 音分；专业频闪调音器标称 ±0.1–1 音分。

### 算法管线（为什么能到这个精度）

```
麦克风(关闭系统 NS/AGC) → 零相位砖墙低通 → YIN(CMND) → ρ(τ) 抛物线精修
   → 工频哼声门限(±8¢ + 纯度判定) → 候选打分/八度选择
   → 谐波峰拟合非谐性 B → 刚度补偿 f1 = f/(1+B·k²eff/2)
   → 中值滤波 + 卡尔曼平滑 → 稳定 ≥250ms 后给出"准了"判定
```

关键设计（每条都踩过坑，详见代码注释与测试）：

- **零相位低通**：近奈奎斯特的谐波会让 τ 域插值失效，必须在时域先滤掉
  （`min(0.22·sr, max(6000, 2.5·fmax))`），且必须零相位，否则引入群延迟偏差。
- **ρ(τ) 精修**：YIN 的差函数谷底插值有偏；改用归一化自相关 ρ 的峰顶插值，无偏。
- **非谐性补偿**：真实琴弦谐波被刚度拉伸，音头综合音高比基频高几音分——
  这不是算法误差而是物理。用谐波峰加权回归拟合 B，再解析补偿。
- **工频哼声**：50/60 Hz 及其谐波与乐音可能只差几十音分（D3 距 150 Hz 仅 37 音分），
  用 ±8 音分窗口 + "2/3 次谐波是否比基频弱 18 dB" 的纯度判定区分哼声与乐音；
  纯哼声直接判为无信号，绝不锁定。
- **稳定后读数**：补偿与平滑需要收敛时间，判定要求音符稳定 ≥250 ms。

## 立即使用（PWA）

```bash
cd tuner
python3 -m http.server 8080        # 本机：http://localhost:8080
```

手机上需要 **HTTPS 或 localhost** 才允许麦克风：
- 局域网：`python3 -m http.server 8080 --bind 0.0.0.0` 后用内网穿透/自签证书，或
- 部署到任意静态托管（GitHub Pages / Cloudflare Pages / Vercel 均可，纯静态无后端）；
- 打开后 Chrome「⋮ → 添加到主屏幕」即成 App（离线可用，Service Worker 已内置）。
