① 手机直接用（最快，30 秒）

本页所在站点就是 App 本体。手机 Chrome / Edge 打开后 「⋮ → 添加到主屏幕」，即得到一个离线可用的调音 App，无需下载任何文件。

打开调音器 →

需要 HTTPS 或 localhost 才允许麦克风；安装后首次点「🎤 开始调音」授权即可。

② 下载安装包

读取清单中…

PWA 包：解压后整个目录丢到任意静态 HTTPS 托管（GitHub Pages / Cloudflare Pages / Vercel / 自己的 nginx）即可。
完整包：含全部源码、精度测试与已配置好的 Android 打包工程（见 ③）。

③ 要 APK？需一次构建

本预览沙箱的网络白名单不放行 Google/Maven/Gradle，无法在此编译 APK； 以下任一方式约 5 分钟出包：

  1. GitHub Actions（零本机环境）：完整包里有 android-build/ci/build-apk.yml， 拷到仓库 .github/workflows/ 推送后，Actions 页 Run workflow，产物里下载 APK。
  2. 本机命令行（Node 20+ / JDK 17 / Android Studio 自带 SDK）：
cd jingtiao/android-build
npm install
npm run sync      # 网页资源 → android 工程
npm run apk       # → android/app/build/outputs/apk/debug/app-debug.apk
  1. Android Studio：npx cap open android 后 Build → Build APK(s)。

android/ 原生工程已打好调音所需补丁：麦克风权限声明（Capacitor 会自动弹运行时授权）、 竖屏、屏幕常亮、签名接线、与 PWA 同套图标。详见包内 android-build/README.md。
