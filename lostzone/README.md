# 失落区 / LOST ZONE

> 1～4 人合作 · PvPvE 搜打撤 · 卡通化顶视角 · 大世界碎片化叙事
> 当前进度：**Vertical Slice 可玩版已完成**（浏览器直接玩）

## 🎮 立即游玩

```bash
cd lostzone
npm install
npm run dev
# 打开 http://localhost:5173
```

你是一名拾荒者。旧城空了，东西还在——进去，带回来。别信钟楼。

- **探索**：六区域旧城区（居民区 / 废弃医院 / 仓库区 / 地铁站 / 中央街区 / 广播站）
- **信息**：5 纸条 + 2 日志 + 照片 + 录音，全部挂钩玩法（钥匙、密码、谜题、秘密入口）
- **决策**：深入拿高级资源 / 带着情报撤离 / 触发「第五声」赌一把
- **风险**：锈犬巡逻、精英伏击、死亡丢失战利品
- **奖励**：旧币 + 仓库 + 升级（武器改装 / 护甲 / 背包），推动下一局

## 操作

WASD 移动 · Shift 奔跑 · 鼠标瞄准射击 · 1-6 切换 · E 交互 · R 换弹 · Tab 背包/情报 · F 手电 · Esc 暂停

## 目录

```
lostzone/
├── docs/
│   ├── 美术与场景设计定稿.md   # 美术/场景/叙事设计文档（含概念图引用）
│   ├── 可玩版说明.md           # 玩法、验收清单、后续路线
│   ├── preview-map.png         # 地图布局预览
│   └── concepts/               # 10 张概念图
├── src/
│   ├── core/      # 物品/存档/工具（共享类型，为联机预留）
│   ├── world/     # 旧城区地图生成（六区域+隐藏房间+谜题布置）
│   ├── game/      # 对局逻辑（玩家/锈犬AI/搜刮/撤离/事件）
│   ├── render/    # PixiJS 渲染（程序化矢量美术/光影/粒子）
│   ├── ui/        # 大厅/HUD/情报墙/弹窗
│   └── audio/     # WebAudio 程序化音效
├── tests/         # 15 项冒烟测试（vitest）
└── scripts/       # 地图预览生成
```
