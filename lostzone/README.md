## 已确认的关键决策

- **美术**：高清 2D 手绘矢量卡通（参考 *Super Animal Royale* 的俯视可读性理念，不复制其任何素材）
- **角色**：原创拟人化小动物幸存者（猫 / 兔 / 浣熊 / 狐鸮）
- **视角**：高机位 3/4 top-down（约 55°），伪 2D
- **地图**：旧城区 = 六区域环形结构（居民区 / 医院 / 仓库区 / 地铁站 / 中央街区 / 北部广播站）+ 南部撤离点
- **叙事**：零过场、零主线对话，全部叙事由纸条 / 日志 / 录音 / 照片 / 环境细节承载
- **技术**：TypeScript + Vite + PixiJS（渲染）+ Colyseus（WebSocket 权威服务器），前后端分离
- **包体规划**：网页版轻量（约 150–300MB），本地测试版通过 Tauri 打包为独立桌面应用（约 1GB+，包含高分辨率精灵图集与无损音频）
