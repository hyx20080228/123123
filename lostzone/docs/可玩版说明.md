# 《失落区》Vertical Slice · 可玩版说明

> 浏览器可玩（TypeScript + Vite + PixiJS）。当前为**单人跑通完整流程**版本：
> 搜刮 → 情报链 → 钟楼谜题 → 隐藏房间 → 撤离/死亡 → 回营升级 → 再进。
> 1–4 人联机为下一阶段（架构已按前后端分离预留）。

## 运行方式

### 方式一：双击即玩（零安装，推荐）
1. 打开 [GitHub Releases](https://github.com/hyx20080228/123123/releases)
2. 下载 `LostZone-Playable.html`（单文件，约 640KB，自包含全部代码；`失落区-可玩版.html` 为中文别名）
3. 用 Chrome / Edge / Firefox 双击打开 → 点击「进入旧城区」即可

### 方式二：一键脚本
- Windows（免安装，推荐）：双击 `启动测试-免安装.bat` —— 直接打开单文件版，无需 Node.js
- Windows（完整源码模式，需 Node.js）：双击 `启动测试-Windows.bat`
- macOS / Linux：终端运行 `./启动测试-macOS-Linux.sh`

> ⚠️ `.bat` 脚本均为纯 ASCII 编码（已修复中文乱码报错问题），
> 必须与 `lostzone` 文件夹 / `LostZone-Playable.html` 放在**同一个解压目录**中运行。

> ⚠️ 脚本必须和 `lostzone` 文件夹/单文件 HTML **放在同一个解压目录**中运行，
> 不要单独复制到桌面，否则会报"找不到文件位置"。

### 方式三：命令行（需 Node.js ≥ 18）
```bash
cd lostzone
npm install
npm run dev        # 打开 http://localhost:5173
npm test           # 15 项冒烟测试（地图连通性 + 全对局流程 + UI）
npm run build      # 产物在 dist/
npm run build:single  # 产物为单文件 dist-single/index.html（双击即玩版）
```

## 操作

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| Shift | 奔跑 |

| 1–6 | 切换武器 / 快捷装备 |
| E | 交互：拾取 / 撬箱 / 开门 / 拨钟 / 点唱机 |
| R | 换弹（枪） |
| Tab | 背包与情报 |
| F | 手电筒（地铁会自动亮） |
| Esc | 暂停 |

## 叙事链与玩法联动（设计原则落地）

```
纸条1(居民区花盆) ──钥匙──▶ 护士站抽屉(日志1+药房钥匙) ──▶ 地下药房(抗辐药剂)
纸条2(医院) ──"拨钟3:33"──▶ 钟楼谜题 ──▶ 钟楼地窖(备用电源+照片+钛合金)
纸条3(仓库B7) ──"1024"──▶ 地铁储物间(日志2+信号电源) ──▶ 解锁地窖后门·隧道北闸
纸条4(地铁) ──"818"──▶ 仓库皮卡后备箱(弹药补给)
纸条5(广播站) ──录音带──▶ 点唱机「第五声」──▶ 敌潮+情报×2+广播站后门
备用电源 ──▶ 南部撤离点通电 ──▶ 4 秒撤离成功
```
