# 《失落区 / LOST ZONE》美术与场景设计定稿

> 版本：v1.0 · 定稿日期：2026-09-01
> 阶段：Vertical Slice 前置 · **画面风格 / 场景设计 / 叙事碎片设计**（本阶段不做代码）
> 定位：1～4 人合作 PvPvE 搜打撤 · 高机位俯视 2D/伪 2D · 卡通化 · 大世界碎片化叙事

---

## 0. 一页看完（设计总纲）

```
探索 → 信息（纸条/日志/环境） → 决策（去哪/撤不撤） → 风险（AI 敌人/深入区域）
     → 奖励（战利品/情报） → 升级装备 → 下一局探索（解锁新区域）

视觉关键词：高清矢量卡通 · 高机位俯视 · 小可爱比例 · 强轮廓 · 高可读性 · 有限色板 · 干净分层
```

- **不复制** Super Animal Royale 的角色、地图、UI、素材与具体美术设计。
- **只借鉴** 其「俯视角、可读性、轻量卡通化、地图拾取与战斗反馈」的设计理念。
- 本阶段共 10 张概念图，均存于 [`docs/concepts/`](concepts/)，可用 [`docs/concepts/index.html`](concepts/index.html) 浏览。

## 1. 美术风格白皮书

### 1.1 一句话风格

> **「旧城黄昏」——高清手绘矢量卡通里的一丝温柔与诡谲。**
> 干净的圆角矢量造型 + 粗黑描边 + 有限色板 + 环境叙事细节，让玩家第一眼觉得"可爱、想进去逛逛"，第二眼发现"这里发生过不好的事"。

### 1.2 十二项风格基准（美术验收用）

| # | 基准 | 标准 |
|---|------|------|
| 1 | 视角 | 高机位 3/4 top-down（摄像机俯角约 55°），可见角色全身、地面、建筑与道具 |
| 2 | 比例 | 小型可爱比例角色（头大身小，约 2.5 头身），在 1080p 下角色约占屏幕高度 8%～10% |
| 3 | 描边 | 统一深色描边（线宽随缩放轻微变化），角色描边最粗（4px @1080p），道具 3px，建筑 2px |
| 4 | 色板 | 有限色板：暖沙黄 / 冷蓝灰 / 苔藓绿 / 锈橙 / 信号紫红；任何一屏内主色 ≤ 3 种 |
| 5 | 光影 | 色块化柔光（cel shading），场景一层投影，角色脚下椭圆软阴影；不做写实物理光照 |
| 6 | 轮廓 | 所有可交互物/掩体有独立轮廓，禁止"贴在背景里"的物体 |
| 7 | 可读性 | 角色 ≥ 敌人 ≥ 道具 ≥ 环境 的视觉优先级；拾取物带**发光描边**（见 §4） |
| 8 | 动态 | 角色 8 方向动画、武器后坐力、命中白光、拾取光效、敌人受击僵直 —— 全是"信号式反馈"，节奏快 |
| 9 | 噪声 | 不堆砌细节；同一建造物的装饰密度上限 15%；用「色块 + 少量笔触」表达磨损 |
| 10 | 字体/文字 | 游戏内世界文字（招牌/纸条）为手写感手绘字，UI 文字用圆体中文（如「得意黑/站酷快乐体」风格），禁止宋体 |
| 11 | 包体 | 矢量法线贴图（手绘 2D + 轻度法线光效）追求"高清感"；高分辨率精灵图集按区域分包 |
| 12 | 情感 | 废弃 ≠ 恐怖：用暖色调、植物生长、小猫脚印等传递"被时间温柔遗忘"，异常区域（医院/广播站）才用冷色与信号红 |

### 1.3 色板规范（六区域 + 通用）

| 区域 | 主色 | 辅色 | 强调色 | 语义 |
|------|------|------|--------|------|

### 1.4 材质与"旧城"语言

通用道具词汇表（每个区域复用同一套"家族"，换色换形）：

- 覆盖植物：苔藓垫、藤蔓垂挂、梧桐叶、杂草丛（低矮，不挡视线）
- 废弃交通：锈自行车、电动车、小轿车（可作掩体，可翻找）
- 生活残留：晾衣绳、搪瓷盆、竹编篮、老式立柜、搪瓷茶缸
- 城市痕迹：褪色海报、卷闸门、广告牌、电线杆、涂鸦
- 特殊对象（叙事）：**红纸条、黄色示警条、蓝白色密封箱、信号灯** —— 世界碎片专用视觉语言

## 2. 角色设计（四名原创小动物幸存者）

> 原则：小可爱、强剪影、单色身份；每名角色一张技能基调（本阶段仅定外形与故事钩子）。

| 角色 | 动物 | 配色身份 | 特征 | 叙事钩子 |
|------|------|----------|------|----------|
| 阿橘 | 橘猫 | 暖橙 | 圆滚滚、旧背包、补丁裤、手里常提一盏老式提灯 | 曾是街区杂货铺的猫，镇上第一个"听见钟楼声音"的人 |
| 小白 | 垂耳兔 | 灰蓝 + 红围巾 | 长耳垂、护目镜、红色围巾（异常来客的标志） | 围巾是"十四日"当晚唯一的未解线索，她本人却什么都不记得 |
| 老浣 | 浣熊 | 墨绿马甲 | 工具箱、扳手、独眼罩 | 旧城水管工，知道所有地下通道，包括不该存在的 |
| 灰鸮 | 狐鸮 | 冷蓝 | 相机挂脖、长羽耳、哨子 | 自由摄影师，事件前最后一卷胶卷在他相机里 |

**角色动态规范**

- 8 方向移动（下/上/左/右 + 4 斜向），每方向 6 帧行走 + 4 帧待机呼吸
- 武器持握位固定在右手侧，换武器时有 0.15s 抬枪动作
- 受伤：白闪 + 短僵直；死亡：卡通化"叹号 + 倒地 + 灵魂小泡泡"，并掉落战利品袋
- 角色脚下触地投影 + 头顶名牌（队友绿/敌人红/自己青）

## 3. 旧城区 · 场景设计

### 3.1 地图总览（见 `02-地图总览-旧城区.png`）

**核心结构：环形 + 十字主轴**

```
                     ┌─────────────┐
                     │ 北部广播站   │  ★高难度/信息核心
                     └──────┬──────┘
                            │
   ┌──────────┐      ┌──────┴──────┐      ┌──────────┐
   │ 居民区    │─────▶│  中央街区    │◀─────│ 仓库区    │
   │ (低风险)  │      │ (钟楼/枢纽)  │      │ (物资)    │
   └──────────┘      └──────┬──────┘      └──────────┘
                            │
                     ┌──────┴──────┐
                     │ 地铁站       │  ★垂直探索
                     └──────┬──────┘
                            │
                     ┌──────┴──────┐
                     │ 南部撤离点   │  ◀ 安全撤离流程
                     └─────────────┘
```

**设计要点**

1. **玩家不能一眼看到高级资源**：高级资源箱（信号色描边）全部位于建筑内部或需钥匙/密码，地图上无全局高亮。
2. **每区域风险 = 奖励**：见下表；且**信息密度**与物资等级成正比。
3. **路线可回环**：任何两区域之间至少两条路径（地面主路 + 巷子/隧道支路），支路通常更危险但更快。
4. **掩体密度**：主路每 10m 至少一个可卡位掩体；所有门窗进入战斗态自动"可关闭"（门后防弹视线）。
5. **特殊地块**：① 地铁站隧道 → 钟楼地窖（隐藏房间）；② 医院地下配药室；③ 仓库信号车；④ 广播站控制室。

#### G. 南部撤离点（南 · 目标区）
- 灰白停机坪 + 绿色信号灯 + 遮蔽帐篷（见 `02-地图总览` 底部）
- **安全撤离流程**（本阶段定为 Vertical Slice 目标）：
  1. 玩家需在**钟楼地窖（隐藏房间）**取得「备用电源」；
  2. 到达撤离点后 3 秒通电 → 提示"可以撤离"；
  3. 站上信标 5 秒（被打断则重置）；
  4. 倒计时结束 → 撤离成功结算（保留战利品、写入情报日志）；
  5. 死亡 → 掉落大部分战利品 → 回到大厅（营地）结算。

   - 内容：日志 2、信号电源、老式磁带机
3. **广播站控制室**
   - 内容：纸条 5、录音带「倒放 33」、对应"第五声"特殊事件
4. **医院地下药房**
   - 内容：抗辐药剂、封锁日志副本（照片墙）

## 4. 拾取与战斗可读性规范（核心）

> 参考 `09-拾取与武器-可读性演示.png`：所有地面物品 = **本体剪影 + 发光描边 + 投影**，三要素缺一不可。

### 4.1 地面物品发光描边（按种类配色）

| 物品 | 描边色 | 呼吸动画 |
|------|--------|----------|
| 近战武器（砍刀） | 品红 `#FF4FA0` | 慢呼吸 |
| 枪械（手枪/SMG） | 红 `#FF4A3C` | 慢呼吸 |
| 护甲 | 蓝 `#3FA9FF` | 慢呼吸 |
| 普通资源 | 白 `#E8F6FF` | 无（静止） |
| 高级资源 | 金 `#FFC23C` | 中速 + 星点 |
| 纸条/日志/录音 | 紫 `#B26BFF` | 中速 + 微浮动 |
| 钥匙/密码类 | 青 `#59E6D9` | 快速脉冲 |
| 医疗 | 绿 `#59C46A` | 慢呼吸 |

- 物品拾取半径 0.6m，拾取后 0.4s 白色收束光效。
- 远处（>12m）只显示"光点"不显示实体，防止屏幕噪声。
- **优先级遮罩**：枪械描边 > 护甲 > 资源 > 纸条；同屏小概率互斥（按价值保留）。

### 4.2 敌人（第一阶段 1 种：锈犬 Rust Hound）

- 造型：小型四足铁皮巡逻犬，锈橙铁皮 + 一条信号灯尾巴；受击掉落金属零件。
- 行为：巡逻 → 发现（头上"!"）→ 追击（速度略慢于玩家）→ 近距挥爪（0.5s 前摇红光）→ 脱战回位。
- 视觉反馈：受击白闪+零件飞溅、残血冒烟、死亡断电火花 + 掉落品。
- 未来（非本阶段）：医院"看护者"、仓库"叉车兵"、广播站"天线守卫"。

### 4.3 战斗反馈基准（帧级）

- 武器切换 0.15s 抬枪；射击后坐微位移 + 枪口闪光；命中白色菱形爆闪；命中反馈音（三选一随机 pitch）。
- 玩家受击：红屏边缘 + 角色白闪；敌人受击：0.1s 硬直 + 后仰。
- 弹药不足：枪口打滑音 + 弹药 HUD 红色抖动。
- 撤离信标：绿光脉冲，进入范围 UI 显示"正在撤离 3…2…1"。

> **「十四日，凌晨 3:33」**
> 2029 年 9 月 14 日，澜川市旧城区的广播电台发生了一次短促的"信号事故"。当夜，全城所有钟表停在 3:33，广播里只有一个倒放的旋律，循环播放到天亮。
> 第二天，市政以"管道检修"为由封城；第三天，居民被引导撤离；一周后，城市正式划为"失落区"。官方解释是"有害物质泄漏"，但撤离名单上少了一个人——广播站的值班员。
> 唯一的"异常来客"是戴红围巾的兔子。她记不得自己来自哪，只记得那晚在钟楼下面听到过"第五声"。

**「钟楼 3:33」**

- 玩家需把钟面指针拨到 **3:33**（纸条 2 提示）；

#### 隐藏房间（1 个）

**「钟楼地窖」**

- 风险：开门后 10 秒，广播站方向会刷 1 波锈犬（房间有后门可逃）。

#### 特殊事件（1 个）

**「第五声」**
- 前置：完成纸条 2 + 纸条 5 链（读过即可，不要求持有道具）；
- 触发：携带「录音带」（广播站内获得）在钟楼旁空地旧点唱机使用；
- 结果：夜空变紫红（全图可见）→ 钟楼响亮一声（全图听到）→ 中央街区刷 1 波精英敌潮；
- 奖励：本次撤离结算时，**信息类战利品价值 ×2**，并永久解锁「广播站后门」通行（下次开局生效）。

### 5.3 碎片收集与"情报面板"

- 玩家收集的纸条/日志/照片自动进入**情报面板**（按时间线排序成"事件墙"），可回看全文。
- 收集率按区统计：任何一区 100% 收齐 → 该区地图上标出"密道/剩余高级箱"（奖励探索而不是惩罚错过）。
- 收集品**可出售**（换资源），但出售会永久失去该碎片 → 形成"信息 vs 资源"的决策。
- **绝不打断战斗**：碎片只通过"拾取瞬间一句话 + 回营地细读"呈现。

## 7. 技术选型与架构（为可玩版本预留）

| 层 | 技术 | 理由 |
|----|------|------|
| 语言 | TypeScript（strict） | 前后端共享类型（物品/区域/伤害协议） |
| 构建 | Vite | 快、秒级热更，适合浏览器游戏 |
| 渲染 | PixiJS v8（WebGL） | 2D 精灵图集 + 法线贴图光效 + 粒子，性能好 |
| 物理/碰撞 | 自研轻量：网格 + 圆形/AABB 碰撞（先不引重型物理引擎） | 俯视 2D 场景多为"阻挡层"，自研可控、包体小 |
| 地图 | Tiled 编辑器导出 JSON（分区加载） | 区域分包，先加载出生区，其余按需加载 |
| 音频 | Howler.js + 分区环境音 | 事件音/环境音分层 |
| 联机 | Colyseus（Node + WebSocket）权威服务器 | 1～4 人房间制、状态同步简单可靠；后续扩展 PvPvE（AI 服务器判定） |
| 网络模型 | 客户端预测 + 服务器回滚（先做"客户端权威移动 + 服务器校验危险操作"的折中） | 保证流畅与公平 |
| 存档 | 后端 SQLite（先 localStorage 双写） | 撤离战利品/情报墙持久化 |
| 桌面打包（1GB+） | Tauri（Rust 外壳）+ 高分辨率图集 + 无损音频 | 浏览器版轻量；本地下载版做"完全体"，符合 1G+ 交付目标 |
| CI | GitHub Actions：lint + build + 自动化冒烟测试 → Release 资产 | 测试版直接 GitHub Releases 下载 |

**1G+ 资产构成规划**：① 高分辨率精灵图集（角色 8 方向全帧 ×4 角色 + 六区域 x2 分辨率图层）约 350–500MB；② 无损/高码率音频（环境 + 武器 + 音乐）约 300–400MB；③ UI/特效图集与法线贴图约 100–150MB；④ 桌面运行时与字体约 100MB。
